What I learned

Working on this project helped me strengthen:

* How to structure HTML elements efficiently using nested divs and sections

* Combining Flexbox and Grid effectively

* Styling with Google Fonts and creating visual hierarchy using weight and color

* Creating responsive layouts with media queries

* Applying subtle shadows and border radiuses to match a UI design system

Here’s a snippet of CSS I’m proud of:

@media(min-width:600px){
  .CARD{
    display:grid;
    grid-template-columns: 1fr auto 1fr;
    align-items:center;
    gap:22px;
  }
}
